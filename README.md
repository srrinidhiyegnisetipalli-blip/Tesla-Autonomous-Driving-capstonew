# Autonomous Driving and Tesla Road Safety Analysis

## Overview
This capstone project focuses on autonomous driving and road safety analysis using deep learning and data analysis techniques. The project is divided into two parts. The first part works with vehicle images to build a CNN-based model for vehicle classification and bounding box prediction. The second part analyzes Tesla accident records to understand patterns related to deaths, autopilot involvement, vehicle models, and accident distribution.

## Project Highlights
- Extracted and prepared autonomous vehicle image data
- Loaded image labels containing class and bounding box information
- Preprocessed vehicle images using OpenCV
- Built a Convolutional Neural Network using TensorFlow/Keras
- Created a multi-output model for vehicle class prediction and bounding box regression
- Evaluated the trained model on test data
- Ran inference on sample images and visualized predicted bounding boxes
- Cleaned and analyzed Tesla accident data
- Performed exploratory data analysis on accident events by year, day, country, state, model, and death-related features

- Analyzed accident event trends across years, days, countries, and states
- Studied accident-related features such as deaths, Tesla driver deaths, Tesla occupant deaths, cyclist/pedestrian involvement, model-wise events, and verified Tesla autopilot deaths
